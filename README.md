# Lost Souls

## 📋 Mô tả dự án

Lost Souls (Vong hồn ký) là một dự án game 2D phục vụ cho môn học "Dự án 1 - PRO124"

## 🛠️ Công nghệ sử dụng

- **Game Engine:** Unity
- **Ngôn ngữ lập trình:** C#
- **Loại game:** 2D Platformer

## ✨ Tính năng chính

- Di chuyển và điều khiển nhân vật
- Hệ thống camera theo dõi (Camera Follow)
- Animation cho các đối tượng trong game
- Cơ chế kỹ năng chiên đấu 2 hệ
- Cơ chế chuyển đổi thế giới
- Cơ chế giải đố và đánh quái
