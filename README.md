# PRO124 - Dự án 1

## 📋 Mô tả dự án

Dự án game 2D phục vụ cho môn học "Dự án 1 - PRO124"

## 👤 Người thực hiện

**Lê Phan Hòa Thuận** (lphthuan)

## 📅 Thông tin dự án

- **Ngày khởi công:** 06/08/2025
- **Ngày cập nhật:** 30/12/2025
- **Tình trạng:** Đang phát triển

## 🛠️ Công nghệ sử dụng

- **Game Engine:** Unity
- **Ngôn ngữ lập trình:** C#
- **Loại game:** 2D Platformer

## ✨ Tính năng chính

- Di chuyển và điều khiển nhân vật
- Hệ thống camera theo dõi (Camera Follow)
- Platform controller và pass-through platforms
- Hệ thống ladder (thang leo)
- Exit/checkpoint system
- Animation cho các đối tượng trong game
- Hệ thống enemy và combat
- Hệ thống puzzle và môi trường tương tác
- Hệ thống soul (linh hồn) và pickup items
